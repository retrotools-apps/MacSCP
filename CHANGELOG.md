# Changelog

## [1.2.0] (2026-10-27)

### Highlights

* **appearance:** Reminders-inspired contrast, appearance pickers and compact sidebars.
* **tunnels:** Filtering, management menus and confirmed port recovery.
* **fixes:** Preserved sidebar width, fixed first SSH launch and removed the integrated terminal.

## [1.0.0] (2026-10-25)

### Highlights

* **transfers:** Transfer files and folders with SFTP over SSH, S3-compatible storage and WebDAV, with queues, conflict handling, bandwidth limits and checksums.
* **connections:** Organize saved connections and reusable logins in nested groups with searchable icons, custom colors and a native macOS interface.
* **tunnels:** Manage local and remote SSH forwarding and SOCKS5, with jump hosts, TLS gateways, automatic startup and reconnection.
* **files:** Edit UTF-8 documents, preview text and hexadecimal data in bounded windows, and search SSH folders without downloading complete files.
* **workflows:** Pair two SCP tabs for remote-to-remote copies through the Mac, or server-side copies on the same SSH endpoint. Open external editors and SSH terminals.
* **diagnostics:** Check the configured connection route, trace failed connections, inspect connected-server information and measure upload/download throughput in Mbit/s.
* **security:** Keep saved passwords and passphrases in macOS Keychain. Confirm unknown SSH host keys; changed host keys stop the connection.
* **languages:** Use MacSCP in English, French, German, Spanish, Italian, Romanian or Polish.
* **updates:** Install direct-distribution updates through signed Sparkle feeds and archives, with explicit installation and relaunch confirmation.
