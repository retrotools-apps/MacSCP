MacSCP user guide

Use MacSCP to browse remote files, transfer documents and manage SSH tunnels. It requires macOS 15 or later and runs on Apple Silicon and Intel Macs. The interface is available in seven languages; this guide uses the English names of buttons and menus.

Connect to a server

  1. Choose New connection.
  2. Select SSH/SFTP, S3 or WebDAV, then enter the server address and your authentication details.
  3. Save the connection to find it again in the sidebar or All connections.
  4. Double-click its card to connect.

For SSH, use a password, a private key or your local SSH agent. Passwords and key passphrases are saved in macOS Keychain.

On your first SSH connection, check the host-key fingerprint with the server administrator before accepting it. If a saved key has changed, MacSCP stops the connection. Verify why it changed before updating the saved key.

Organize and import connections

Use groups and subgroups to keep related connections together. Click a group's chevron to expand or collapse it, and use its color dot to choose a color. Dissolving a group keeps its connections.

To import connections, open the Sessions menu and choose the appropriate import action. Supported formats include OpenSSH configuration entries, Cyberduck SFTP/S3 bookmarks, WinSCP INI files and MacSCP exports. Review the imported settings before connecting; some options from other clients are not supported.

Open several connections in separate tabs. Disconnect ends a file session while keeping its tab; ⌘W closes the tab. Use ⌘1–9 to select a tab, or ⌃Tab and ⌃⇧Tab to move between tabs.

Browse and transfer files

The file workspace shows your Mac on the left and the remote server on the right. Open folders or use the path bar to navigate. Home, Root and Up take you to common locations.

To upload, drag files or folders from the local pane to the remote pane. To download, drag them in the opposite direction. You can also select items and press Space, or use the context menu. Drag remote files to a Finder folder to download directly into it.

Follow progress in the source tab's transfer queue. If a file already exists, choose whether to overwrite it, skip it or use another name. You can cancel transfers and set bandwidth limits. Resume is available only for supported protocols and operations.

View or edit a file

Select a file and choose File → View (F3) or File → Edit (F4). Depending on your keyboard settings, you may need to hold Fn.

The viewer displays text or hexadecimal data, including parts of large remote files. The editor is intended for UTF-8 text. Both open in separate windows that stay open when you switch tabs.

  • Press ⌘S to save in the editor.
  • In the viewer, use ⌘F to search and ⌘G / ⇧⌘G to move between matches.
  • Press ⌘W to close the document window. MacSCP asks before discarding unsaved edits.

Save before disconnecting: disconnecting a session closes its viewer and editor windows. External-editor saves can upload changes back to the server.

For SSH connections, directory search can find files by name or look for literal text in their contents. You can also request a checksum to compare files; check its displayed type before comparing values.

Copy between two remote servers

  1. Open two SCP sessions.
  2. Drag one tab onto the center of the other. The dragged session appears in the left pane. Dropping near an edge reorders tabs instead.
  3. Select files and transfer them using drag and drop, Space, the context menu or the pane's arrow.

The paired header shows the copy route. Between different servers, files pass through your Mac. When both panes use the same SSH server, account and connection route, MacSCP can copy directly on that server. Direct copies require a POSIX shell with cp; if the server cannot perform the operation, the copy fails.

A shared jump host does not enable a direct copy between different servers. Different host aliases are not automatically treated as the same server. You cannot copy a file onto itself or a folder into itself.

Choose Local / remote view to return to the usual layout. Both connections stay open and queued copies continue. Closing a destination tab cancels copies being sent to it.

Open an SSH terminal

With an SSH connection selected, click SSH or press ⌘T. MacSCP opens the terminal application configured in Settings, such as Terminal or iTerm. It has its own SSH session, separate from the file browser.

Create and manage tunnels

Switch to Tunnels and choose New tunnel. Select the forwarding type, choose a saved SSH connection and enter the required ports and destination. Save the tunnel, then choose Start.

  • Local forwarding makes a service reachable through a port on your Mac.
  • Remote forwarding opens a listening port on the SSH server.
  • SOCKS5 provides a local proxy for applications configured to use it.

For local and SOCKS tunnels, use 127.0.0.1 as the listening address to keep access limited to your Mac. Use another address only if other machines should reach the port.

Tunnels run independently of file tabs. Disconnecting a file session does not stop them; use Stop when you no longer need a tunnel. Active local HTTP and HTTPS tunnels can be opened in your browser.

Find and change a tunnel

In All tunnels, enable Active only to show established tunnels, including degraded connections. Turn it off to see stopped, connecting and reconnecting tunnels too. Start all and Stop all apply to all tunnels even when the filter is enabled. Use groups to start or stop related tunnels together.

Right-click a tunnel, or open its … menu, to rename, duplicate, edit, move or delete it. Renaming leaves it running. Saving an edit stops the tunnel; start it again to apply the changes. Deleting asks for confirmation and stops it.

Duplicating opens a new tunnel to review before saving, with automatic start disabled. MacSCP suggests a free local port; for remote forwarding, choose another remote listening port yourself.

If a port is already in use

Choose another listening port in the tunnel editor, or, for a local or SOCKS tunnel, choose … → Free port and restart…. Review the application names and process IDs before confirming: this terminates those processes, forcibly if needed, and their unsaved work may be lost. macOS asks for administrator authorization when required.

MacSCP restarts the tunnel only after freeing the port. This action cannot free a port on a remote server.

Start tunnels automatically

In Settings → Startup, choose whether to open MacSCP at login, restore windows or start configured tunnels. Restored file tabs remain disconnected until you connect them. Configure automatic reconnection separately for each tunnel. The menu bar icon also provides tunnel status and start/stop actions.

Customize the display

Open Settings → View to adjust contrast and the sidebar.

  • Choose Low contrast for subtle group backgrounds or High contrast for stronger colors and more distinct text and icons.
  • Use Color group backgrounds to show or hide group colors. Your saved colors remain available.
  • Enable Compact sidebar to hide status dots, connection protocol labels, tunnel indicators and generated tunnel port suffixes. Group color dots are also hidden; your chosen identity icons remain visible.

Drag the divider to resize the sidebar. Hiding and showing it keeps the width you chose in that window.

To personalize a connection or tunnel, open its editor and choose a color and icon. Use the circular palette or the color picker for a custom color. Search the icon grid by name or keyword, or choose a Family to narrow the selection. The grid combines system symbols, Tabler Outline icons and application logos.

Diagnose a connection problem

Right-click a connection, choose Diagnose…, then Run check. Before connecting, checks help investigate name resolution and server reachability. If the connection fails, route tracing can help locate the problem. A router that does not reply does not necessarily indicate an outage.

For connected SSH sessions, diagnostics can show the operating system, uptime, memory, disk space and network addresses. Available details depend on the server. Linux and macOS are supported; Windows results may be incomplete. These checks require no administrator privileges.

Public-IP discovery is optional and disabled by default. If enabled in Settings, the server may contact ipify, OpenDNS or Google DNS to identify its public address.

Throughput test measures upload and download speeds between your Mac and the server. It creates a temporary file on the server, downloads it and removes it. You need write permission, and configured bandwidth limits apply. The result is not a measurement of your Mac's Internet speed.

Use Copy report to share results with an administrator. Review reports and logs first: they can include server names and paths. Never share passwords or private keys. Diagnostic logging is disabled by default and can be enabled in Settings when troubleshooting.

Keep MacSCP up to date

For GitHub installations, open Settings → General → Updates or choose Check for Updates from the application menu. MacSCP asks before installing an update and relaunching. If automatic updates are unavailable, download a package from GitHub Releases. GitHub packages are not Apple-notarized.

Mac App Store installations are updated through the Store. If you built MacSCP from source, rebuild it to update, or install a GitHub package. Build instructions are available in the project repository.

Compatibility and help

MacSCP supports SFTP over SSH, S3-compatible storage and WebDAV. FTP, SMB and AFP are not supported. SSH connections can use one jump host and supported TLS-gateway settings; multi-hop jump chains are not supported. RSA authentication requires SHA-512 signature support. If SSH agent authentication is rejected after several attempts, reduce the identities offered by your agent. Route tracing supports IPv4 only.

When exporting connections, follow the dialog's encryption options to protect credentials. WinSCP export requires a master password.

Report ordinary bugs through GitHub Issues. Include the MacSCP version and steps to reproduce the problem, with sensitive information removed. For suspected vulnerabilities, follow the security policy.
