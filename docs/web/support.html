MacSCP support

Documentation, issue reporting and security contacts for MacSCP.

DocumentationQuestions and problems Security reportsWhat to include

Documentation

Start with the MacSCP user guide for connections, file operations, external terminals and managed tunnels. Recent changes and known compatibility details are listed in the release notes.

Questions and problems

Support is provided through the public MacSCP issue tracker on GitHub. It can be used to report a reproducible problem, request clarification or suggest an improvement. A GitHub account is required to create an issue.

Security reports

Do not disclose vulnerabilities, credentials or private infrastructure in a public issue. Follow the repository's security reporting policy for suspected security problems.

Information to include

Include the MacSCP version, macOS version, connection type and precise reproduction steps. Remove passwords, keys, tokens, private host names, network addresses and confidential file data before sharing screenshots or diagnostics.
