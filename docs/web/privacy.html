MACSCP / PRIVACY

Privacy policy

Effective 29 October 2026. This policy covers MacSCP distributed by RetroTools.

Data collectionUser-directed connections Local storageUpdates SupportYour controlChanges

Data collection by RetroTools

RetroTools does not operate a MacSCP account service and does not collect analytics, advertising identifiers, usage history, connection details, credentials, file contents or diagnostic logs from the application. MacSCP contains no advertising or behavioral tracking.

User-directed network connections

MacSCP connects only when needed for features selected or configured by the user. Host names, account names, credentials, commands and file data may be sent directly to SSH, SFTP, S3-compatible or WebDAV services chosen by the user. RetroTools does not receive or control that traffic. The operators of those services may process data under their own policies.

Opening an external terminal asks macOS to launch the user's selected terminal and the system OpenSSH client. The resulting SSH connection is separate from MacSCP's native file connection and goes directly to the configured server.

Data stored on the Mac

Saved connections, preferences and local audit settings are stored on the Mac. Passwords and private-key passphrases are stored in the macOS Keychain rather than in MacSCP's JSON files.

Diagnostic and audit logs are local. They are designed to exclude passwords, private keys and file contents. RetroTools receives a log only when the user deliberately includes it in a support report.

Updates and external services

MacSCP can contact GitHub to check for signed application updates. Requests to GitHub are governed by GitHub's privacy policy.

Support and GitHub

Support is provided through GitHub Issues. Information posted there is supplied voluntarily and may be public. Users should remove credentials, private host names, addresses and confidential file data before submitting an issue. GitHub processes account and service data under its own privacy statement.

Retention, deletion and user control

MacSCP does not retain user data on RetroTools servers. Users can remove saved sessions and credentials from MacSCP, remove remaining MacSCP entries with Keychain Access, delete local logs and application data, and uninstall the application. Data deliberately posted to GitHub is retained and deleted according to GitHub's controls and policies.

Policy changes and contact

Material changes will be published on this page with an updated effective date. Privacy questions can be submitted through the MacSCP issue tracker without including secrets or private infrastructure details.
